## Projeto em destaque

### 🥬 Modelagem de Banco de Dados - Hortifruti União

[![Projeto](https://img.shields.io/badge/Ver%20Projeto-Modelagem%20de%20Banco%20de%20Dados-2ea44f?style=for-the-badge&logo=github)](https://github.com/TarcisioT/Modelagem-de-Banco-de-Dados-Entrega2)

Projeto acadêmico em grupo desenvolvido a partir de uma organização real, com foco na criação de uma solução de banco de dados para apoiar o controle de **estoque, lotes, validade, perdas, vendas, fornecedores e processos financeiros**.

Durante o projeto, participei do desenvolvimento e estudo de conceitos como:

- Levantamento e entendimento de regras de negócio
- Modelo conceitual e modelo lógico
- Banco relacional em **MySQL**
- Criação e relacionamento de tabelas
- Chaves primárias e estrangeiras
- Normalização
- Triggers e procedures
- Consultas gerenciais e de auditoria
- Indicadores relacionados a perdas, validade, estoque e vendas
- Potencial de uso dos dados em BI e análises futuras

Esse projeto reforçou meu interesse em seguir carreira na área de **Dados**.
